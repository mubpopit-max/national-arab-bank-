# الإمبراطورية إستوري | Empire E-Story

منصة متجر رقمي عربية لإعلانات الحسابات الرقمية، شحن الألعاب، الوكلاء، المحافظ التجارية وEPC.

## الحالة
راجع [تقرير حالة التطوير](EMPIRE_ESTORY_STATUS.md). الكود في هذا الفرع نقطة تطوير موسعة، وليس تصريحاً ببدء استقبال أموال حقيقية.

## التشغيل محلياً أو على خادم
1. أنشئ ملف إعدادات من `.env.example` ولا تضع الأسرار في Git.
2. استخدم قاعدة بيانات ومسار صور على تخزين دائم.
3. أنشئ مفتاح Fernet لتشفير بيانات التسليم.
4. شغّل عبر Docker Compose أو Gunicorn.

مثال:
```bash
docker compose up --build -d
```

يحتاج ملف `.env` إلى `FLASK_SECRET_KEY` و`FOUNDER_PASSWORD` و`FOUNDER_PIN` و`EMPIRE_DATA_ENCRYPTION_KEY`. لا تنشر الخدمة قبل HTTPS ونسخ احتياطي ومراجعة أمنية وقانونية.

## الصفحات
- تسجيل الدخول: `/login`
- المتجر: `/store/`
- المحفظة: `/store/wallet`
- سوق الحسابات: `/store/marketplace`
- شحن الألعاب: `/store/topups`
- الطلبات: `/store/orders`
- مركز المالك: `/store/admin`
- فحص الخدمة: `/store/healthz`

## ملاحظات
- حسابات المتجر منفصلة محاسبياً عن أرصدة النظام البنكي القديم؛ لم يتم ترحيل أموال قديمة.
- تحقق Binance يدوي، ولا يوجد تكامل API آلي.
- تنفيذ الشحن حالياً بتسجيل مرجع المورد من الوكيل؛ لا يوجد مزود شحن آلي متصل.
- EPC رصيد داخلي، لا يوجد تداول خارجي أو سحب.
- PWA قابلة للتثبيت عند نشرها عبر HTTPS. لا يوجد APK أصلي مبني بعد.
